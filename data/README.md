# data/

Everything in this directory is gitignored. It holds the source PDFs and every artifact
derived from them — see "A note on the documents" in the top-level README.

Expected layout:

```
data/
├── INDEX.md                        # generated by split_contract.py; the skill's
│                                   #   navigation index — titles, page ranges, filenames
├── original/                       # source PDFs — you supply these
│   ├── live-contract.pdf           # the PWA
│   └── handbooks/                  # optional; one PDF per reference handbook
│       └── *.pdf
├── extracted/                      # generated by extract_contract.py
│   ├── live-contract-full.md       # merged extraction, with page provenance markers
│   ├── ocr_cache/                  # per-page transcriptions; makes reruns cheap
│   └── handbook_batches.json       # batch ids, from transcribe_handbooks.py
├── page_images/                    # rasterized page PNGs (scratch, regenerable)
├── sections/                       # generated by split_contract.py
│   ├── 00_front_matter.txt
│   └── section_XX_*.txt
├── loa/                            # generated by split_contract.py
│   └── loa_XX_*.txt
├── mou/                            # generated by split_contract.py
│   └── mou_XX_*.txt
└── handbooks/                      # generated by transcribe_handbooks.py
    └── *.md
```

Only `original/` is yours to provide. The rest is created by the pipeline.

Set `PWA_DATA_DIR` to keep this tree somewhere else entirely — outside the checkout, on a
different disk, wherever.
